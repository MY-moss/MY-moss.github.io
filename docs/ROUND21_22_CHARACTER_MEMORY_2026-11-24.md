日期：2026-11-24。仅更新《上岸模拟器》的游戏数据、原生 JS 引擎、测试和文档，未恢复公开信息流，也未清除旧存档。

## 实际发现的问题

1. **负关系判断写反（P1）**：ent169–174 与 ent285–286 使用 requireContactMin:-30；敌对关系从 -30 恶化到 -60 时，后续事件反而无法出现。改为 requireContactMax，最严重冲突门槛调整为 -45，和解后则不再被判为宿敌。
2. **导师故事自相矛盾（P1）**：ent182“恩师康健”和 ent183“恩师辞世”可在未经住院剧情的情况下互不关联地随机触发；关系降低甚至会诱发死亡。这两个事件现在分别对应探访/问候和长期拖延后的回访，不再让玩家是否去探望决定导师生死。
3. **高价值剧情很难遇见（P1）**：第一轮同种子 600 局模拟中，当众批评和抢功风波仅出现 5 次和 3 次。现在在无待兑现旧事的中前期年度槽安排适度的职场分歧与导师相识机会，后续继续遵循玩家选择。
4. **联系人无真实起因（P1）**：新 ent308 让郑教授从公开政策研讨会进入人生；玩家可以主动交流、合作整理问题或选择离开。只有真正建立交往的玩家才有后续“再次来访”，不会直接空降资源。
5. **人与人之间的选择反馈太弱（P1）**：王副科长、张处长的旧矛盾现在连接 2–3 年后的和解、共同署名、独立核查、职场报复等不同结果。合法反映材料不再自动按严重腐败风险结算。
6. **已有导师会被重新初识（P2）**：新增 excludeContact 事件门槛，真实随机事件池、诊断和年度人物入口同时支持。已有郑教授联系人不重复介绍、更不会因为新相识选项降低关系值。

## 真实测试结果

- 全量静态审核：1,834 条事件，0 条结构报警。仍有 1 组性别互斥的见家长事件使用相同选择列表，这并非同局重复。
- 新增 10 项 NPC 连续剧情测试，覆盖负关系门槛、实际关系和解、不同年份回访、导师初识及拒绝、已认识联系人不被覆盖。
- Node 回归：**126/126** 通过。
- Playwright Chrome 五组回归：本地桌面、移动端、存档、线路图和离线缓存等现有流程通过。
- 固定种子 1,000 局生命周期模拟：**1,000 局正常结束，37,812 游戏年，无无解选择**。
- 结局平均晋升 6.89、最终平均财富 376.92、最终平均压力 50.01。
- 交汇剧情 273 次进入、273 次完成回响；郑教授住院剧情 58 次，其中 57 次完成多年回响，剩余 1 次终局前已排入因果待办。终局完整性由测试新断言验证。
