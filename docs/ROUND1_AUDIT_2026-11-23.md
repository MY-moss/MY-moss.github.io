# 上岸模拟器 · 第一轮审计、开发与验收

开发基线：公开仓库 `main`，提交 `b4bebe06227a9dbea3f0ec691237e8a8683f2467`，游戏 v2.1.83。工作分支 `development/first-round-20261123`。**未发布到 main / GitHub Pages**。

## 审计范围及已确认发现

- **P0（已修复）**：`GameEngine.saveState` 使用 `{...state,currentEvent:null}` 强行清掉待选择事件；`migrateState` 再次清掉 `currentEvent`。刷新或读档可跳过重要职业、家庭和事件链的抉择，形成进度断裂。现在保存待办的 choice 对象，读档仅剔除无效的事件对象；`loadState` 对无效档案失败回滚，避免覆盖在内存中已有的局面。已有旧档中已经被历史版本清掉的待选事件无法自动推断重建。
- **P1（已修复）**：`GameEngine.handleEventChoice` 在校验选项下标和资格之前，已写入 `seenEvents` 和 `eventCounts`。非法操作可能把未完成事件当成已完成，破坏后续事件链。现在先检查具体选项与可用性再写进度。
- **P1（已开发）**：事件池很大，孤立的事件即使出现也缺少多年后与某个角色重逢的连贯感觉。基于已有 `flags + _since`、刚性事件链、`contacts`、`careerLog`，增加五个有分支的完整剧情节点（1 开端 + 2 个二年节点 + 2 个五年节点）。不会引入框架或后端。
- **P2（已优化）**：职业阶段缺乏长期支线的就绪提示。新增小型人物纪事卡，标记已采取的策略、等待年限与完成状态，避免剧透后续细节。
- **已核对**：入口脚本、模块顺序、CSS / 离线 CORE 资源列表、浏览器建档/笔试/面试/入职、三种视口、一次真实离线刷新；正式分支不包含 ATLAS 或灵感日报。本轮没有给它们添加任何文件。

## 新增剧情：档案柜里的回执

- **周岚**：固定身份的窗口工作同事，被加入现有联系人系统；关系与信任通过选择变化。
- **开端**：街道遗留的安置回执，可选择公开逐户核验（群众口碑提升、压力增加、职务权重暂损）或内部协调（组织评价暂稳、群众口碑损失、周岚降低信任）。
- **两年后**：公开线遭遇验收附件缺页；内部线遭遇旧名单曝光。每线均有两种可选处理方式，改变廉洁、风险、口碑、关系等数值。
- **五年后**：公开线收到当事人明信片；内部线在老旧楼道与当事人重遇。选择是否再次承担责任，或把经历转化为家庭边界与日后的工作方式。
- **兼容**：沿用现有 `player.flags`、`contacts` 与 `careerLog`；没有改变已有存档文件格式，无需清除旧存档。
- **触发**：就职后第 2–12 年有每年 15% 的入口机会（年度槽空闲时）；已选择路线的后续节点分别延迟 2 年和再 3 年，通过原有刚性链，在未来有空槽时补发。与其他重要刚性链争用同一事件槽，可能出现实际触发推迟。

### 固定种子模拟

`node tests/round1-simulation.cjs`：同一个种子映射与 300 个固定种子，300 个已入职样本，共 3900 个年度；所有样本从 24 岁/工作第 1 年起，模拟 13 年，四种性格、三种政治面貌、不同单位轮换；事件选项在种子 RNG 下选择。

| 实测指标 | 数值 |
|---|---:|
| 人物链开端触发 | 223/300（74.3%） |
| 二年节点触发 | 213 次 |
| 五年节点触发 | 153 次 |
| 公开路径 / 内部路径 | 99 / 124 |
| 平均晋升次数 | 2.21 |
| 模拟末平均净财富 | 116.89 |
| 模拟末平均心理压力 | 50.74 |
| 无可用选项而无法继续 | 0 |
| 早于 13 年结束 | 1（燃尽） |

说明：以上**不是**全年龄、全难度、全背景的考试通过率、正常退休率、结局覆盖率或整个游戏平衡性结论。部分五年节点未触发是因为入口较晚或其他剧情占用年度决策槽。未来应增加完整生命周期的分层仿真。

## 已知问题与后续优先工作

1. 事件剧情还有较多孤立条目，本轮只交付一条完整可玩的持续故事，没有声称所有原有事件链都已审清或可达。
2. 现有晋升流程包含不少硬编码概率、职级上限与名誉修正，需要按部门/年龄/政治面貌进行更多分层统计后才能调整；本轮没有无证据地更改公式。
3. 自动化 UI 验收覆盖了考试成功路径和剧情读档，但尚未覆盖全部家庭、财务、政策项目及所有结局；Service Worker 只覆盖了一次真实离线刷新与资源检查。
4. 本轮没有合并主分支或触发线上正式发布；先在开发分支审查和进一步验收，再由项目所有者决定是否上线。
