# v2.1.90 第七轮：四条人生路线画像

## 目标
把晋升、廉洁、家庭和人脉从散落属性变成玩家能理解的长期人生发展方向；不设置强制职业流派，不因单一低分锁死结局。

## 实现
- 引擎新增 `getLifePathProfile()`，只读计算四条路线：仕途发展、原则与担当、家庭经营、人脉与社会连接。
- 仕途参考领导职级、晋升、单位层级、业务能力与跨级调任；原则参考廉洁、风险、拒绝贿赂、举报与担当及腐败标记；家庭参考家庭属性、家庭压力、婚姻/子女和陪伴/教育计数；人脉参考可信联系人、民间口碑、组织声誉与群众工作经历。
- 所有分数限制在 0–100；不持久化、不更改现有存档、不消耗 AP、不生成额外事件，不改原有结局门槛。
- 生涯页增加“你正在成为怎样的人”四路线画像和动态说明，帮助玩家理解过往积累与生活取舍。
- PWA 版本升级为 v2.1.90，缓存升级到 shangan-pages-12。

## 验证
- 41 项 Node 测试全部通过（包含四条新路线测试、旧事件链和存档回归）。
- Chrome/Playwright 1440×900、390×844、360×740 浏览器回归通过；旧事待办和原有交互无错误，390px 离线加载通过。
- `git diff --check` 通过。

## 边界与下一轮
本轮是可解释的画像，不是已完成的四套独立职业玩法。分数只作反馈，不应该直接等同于结局质量或社会价值。后续应给各路线加入互相牵制的真实事件、人物关系和长期专属机会，并通过策略对照模拟验证，不应简单把画像分数接入结局判定。
