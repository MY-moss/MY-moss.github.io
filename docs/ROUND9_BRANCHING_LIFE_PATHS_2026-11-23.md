# v2.1.92 第九轮：动态分支与长期记忆

## 设计目标
把“路线状态画像 + 固定后续剧情”升级为“玩家选择驱动的动态连续剧情”。旧事件模板不被修改，按当前存档复制事件并注入分支文本与效果。

## 已实现
- 新增 `GameEngine.getLifePathEvent(event)`，覆盖仕途、原则、家庭、社会连接四条路线的中期与长期节点。
- 中期事件读取起点分支，重写场景、人物记忆和选择结果；长期事件进一步读取中期复盘分支。
- 四线交汇场景列出玩家真实经历，针对家庭、原则和社会连接的历史选择改变选项效果。
- 18 种分支情境均有测试覆盖；确认动态副本不会污染静态事件模板。
- 待办清单增加路线专属名称；路线图显示中期处理方式与交汇结局倾向。

## 验证
- Node 自动化测试 46/46 通过。
- 300–500 种子剧情模拟、200 个生命周期样本、3000 组经济数值模拟通过。
- Chrome 桌面与 390/360px 移动浏览器回归通过；离线模式、事件面板、人生线路图和待办列表无页面错误、无资源 404。
- JS 语法、脚本引用、Service Worker 预缓存与 `git diff --check` 通过。
