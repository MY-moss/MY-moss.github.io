# 《上岸模拟器》v2.1.87 · 长局系统审计及修复

基线：正式版 `main` 提交 `a31eb0edbd6a575f6a689779f543907036fe20b7`。本轮仅更新原版职业模块、事件判定、面板和测试，没有创建 ATLAS 或日报系统；不改变本地存档键。

## 已证实的问题

| 优先级 | 具体问题 | 修复 |
|---|---|---|
| P0 | 55/60 岁退休检查可能在已有未完成的剧情选择时插入 `e110` 返聘邀请，覆盖玩家正在阅读的事件；如果邀请因待办事件而被跳过，退休年龄判定仍可能直接结束游戏 | `checkEndings()` 在退休窗口检查事件/晋升/调任待处理状态，保留原事件，待处理完成后恢复判定 |
| P0 | 返聘老年剧情由 `_rcy_specialEventInjection()` 在年度末直接写入 `currentEvent`，未检查已有选择或待办调任/晋升 | 增加完整槽位门槛，已经打开的事件不会被替换 |
| P1 | 常规晋升用 `yearsWorked - promotions` 作为“现职任职年限”。例如入职 20 年、去年刚晋升的干部仍会被误判为已任职十余年 | `getPromotionReadiness()` 用上次晋升的履历年龄或新增 `rankSinceAge`，对无法重建的旧档保留兼容兜底；晋升成功更新任职起点 |
| P2 | 玩家无法看懂为什么暂时不能申请常规晋升 | 职业主面板新增现职任职年限与明确的基础条件阻断理由。这个提示只说明基础资格，不保证晋升成功 |

## 验证

- Node 单元/结构回归：`node --test tests/game-smoke.test.mjs tests/round1-engine.test.mjs tests/round2-content.test.mjs tests/round3-content.test.mjs tests/round4-regressions.test.mjs`。
- 固定种子模拟：`node tests/round3-simulation.cjs`，500 局、最多 16 年，用于新旧内容回归。
- 退休长局：`node tests/round4-lifecycle.cjs`，200 个固定种子、47 岁起最多 21 个职业年度，覆盖女性 55 岁退休、返聘、退休结局与人物事件的共存。该模拟不是所有结局的完整覆盖，也没有让全部生活选择按玩家最优策略进行。
- Playwright：复用 `tests/round3-browser.cjs` 和 `tests/round1-exam-browser.cjs`，检查桌面和两类手机尺寸、PWA、重新加载、职业面板与考试主流程。部署后再检查生产版。

## 仍有价值的下一轮

1. 将事件对“当前职级变动”的更新集中到单一函数（包括罕见的事件直升/基层返聘），避免长期分支之间的任期字段偏差。
2. 用不同职业发展策略做成组对照，而不只用随机策略，评估家庭与职业之间是否真的存在机会成本。
3. 针对存档中仍未处理的晋升/调任/特殊事件建立统一可见的“待办”状态，避免部分显示入口被隐藏。
