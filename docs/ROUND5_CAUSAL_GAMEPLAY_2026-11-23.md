# 《上岸模拟器》v2.1.88：因果交汇、人生线路图与数值回归

基线：GitHub `main` v2.1.87，合并提交 `ffaf8cb6c1f842a4480d9899431d91aabe5a96dd`。本轮沿用原生 JS、浏览器存档、原模块化文件和 Service Worker；不恢复任何 ATLAS/日报系统。无额外 API Key、后端或框架。

## 1. 审计判断与实际修复

现有 1,799 条事件中，长期链条多是互不关联的单独故事。虽然它们有多年后续，却很少让不同人物、生活与工作决策重新相遇；结果是玩家不容易理解不同人生选择彼此的影响。本轮不清退有效的老事件，只添加 **8 个经过结构检查的关联节点**，总数 **1,807**。

本轮发现并修正的数值与体验问题：

- **P1 固定无风险收益过高**：定期每年投入 10、返还 12（净赚 2，20%）；黄金投入 70，固定返还 80（无风险净赚 10，14.3%）。使高流动资金可持续套利，降低风险投资的策略差异。调整为定期返还 11（净赚 1）；黄金分布为 25% 返还 60、55% 返还 74、20% 返还 84，存在亏损，模型期望净赚 2.5。此为**游戏平衡设定**，不代表真实金融收益。
- **P1 消费/理财行动提示隐藏代价**：旧 UI 的 `_posOnly()` 主动删除财务项目中负面增减；不利于玩家判断机会成本。现在展示完整文案，补充贵金属的明确区间及副业风险。
- **P2 跨系统因果孤岛**：旧城回执、许砚团队、林默创业及家人线本来相互独立。现在至少走过“旧城回执 + 许砚或林默”的两组故事，才有机会遇到联合会商。根据既往决定和家庭状态注入不同文本及代价；原有人脉信任和声誉、廉洁、民望、风险、工作压力联动。
- **P2 叙事回顾只是一串流水账**：新增**人生线路图**，使用真实 `seenEvents`、`flags` 推导节点状态。显示过去四条人物故事、三份名单的交汇、两年后、五年后及最终制度回声，不提前揭示未经历的具体结果。手机端两列节点可换行。

## 2. 新剧情《会商桌上的三份名单》

*触发条件*：已参加旧城回执线，并参加过许砚团队线或林默创业线，已工作七年以上且年龄 30–49 岁，年度事件槽空闲时有每年 36% 的机会进入（未满足条件绝不从随机池裸触发）。如果到期有更早的既有因果链或政策项目，该年优先处理旧待办，新联动稍后出现。

故事结构：

| 阶段 | 节点 | 真实变化 |
|---|---|---|
| 交汇起点 | `arc_crossroads_1` | 公开核对 / 分批推进 / 按原口径签发，三条不同策略 |
| 两年后 | `arc_crossroads_(open|phase|seal)_2` | 三类复核问题及不同修复或隐瞒代价 |
| 再三年后 | `arc_crossroads_(open|phase|seal)_3` | 年轻干部交接、留痕与既往错误回响 |
| 再两年后 | `arc_crossroads_echo` | 新一代再次面对相似问题，可带新人核对、独立移交或重走捷径 |

不是单一循环事件：不同选项设置 `crossOpen`、`crossPhase`、`crossSeal` 及相应 reviewed/resolved/legacy flags；通过已有 `_since` 时间记录与刚性链分期兑现，写入人生年鉴并随浏览器本地存档保存。结尾让类似问题再次出现、让玩家有机会改变做法，不重置过去。
