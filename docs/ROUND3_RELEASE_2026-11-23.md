# 《上岸模拟器》v2.1.86 · 正式发布前审计与交付记录

基线：2026-11-23 GitHub 开发提交 `baee912a1ffe58fd6a7373875b5c1ded10a791a9`，继承 v2.1.84-dev（存档与事件链修复）和 v2.1.85-dev（事件精简与人物叙事）。本轮在原静态 HTML/CSS/JavaScript 工程内增量迭代，不引入账号、后端或模型 API Key。**此文档的数值来自发布前本地实际运行。**

## 1. 全量事件审核

自动化读入真实 `GameData.events`，逐条输出 `docs/EVENT_CONTENT_AUDIT_ROUND3.csv`：每个事件有 ID、标题、源文件、阶段、类型、选项数、结构状态、已知警告和部分前置条件。基线 1,795 个事件，本轮删除 2 个重复价值较低的消费片段（`e134` 网购纠纷、`e176` 网红餐厅），新增 6 个跨年节点，最终 **1,799 个事件**。

第一、第二轮余下的 **28 个结构性文案复审候选**本轮逐项处理，包括五条缺乏现场细节的短场景、十五项过短选择、六个选择过多的事件（两个原本重复低价值的小事件已移除）。

本轮完整结构规则：无事件 ID 重复、无无效效果选项、无选项机械结果完全相同、无少于 2 或多于 5 个选项的普通选择事件、无定义文本少于 33 字或选择文字少于 6 字的事件。**结构警告归零不意味着所有 1,799 条文本都经过人工文学质量审校。** 目前静态规则还提示 20 项事件的前置 flag 不是在其它事件效果中产生，主要是 `grassrootsActive`、`hasContact`、`rehired` 等由引擎设置的标记，这些不是已证实的失效剧情，详情见审计报告脚本输出。

### 保留历史、修复重要决策

`e018` 熟人请托从九选一压缩到四条有区别的合规/违规路线；`e093` 上级关系从八选一精简为四种交流方式；`e094` 创业旧同学从九选一重写为三条带有多年后果的路线；`e237` 调查谈话保留坦白、隐瞒、拒绝、推责、逃跑五类策略和旧 flag；`e257` 上级领导求助从九选一压缩为四种协作边界；`e663` 家庭医疗支付由六选一压缩为四种实质性的经济取舍。保留与原人脉、廉洁风险、调查后果相关的字段，不改既有事件 ID。

前两轮叙事中的周岚、许砚、家庭照护仍在本轮继续保留。

## 2. 新剧情《老同学的申请书》

以重写后的旧事件 `e094` 为起点，林默带着创业材料求助，选择可形成三条相互区别的旗标：

1. **公开协助** `classmateOpen`：协助准备公开申报材料；两年后复核企业公开报表，五年后重访车间。长期信誉与工作能力取舍。
2. **私下请托** `classmateFavor`：依靠影响力打招呼；两年后审查函要求核实联系人与旧记录，五年后旧账可能再次追上来。廉洁、风险、热度与朋友信任长期冲突。这条路线需要背景达到 40 的真实门槛。
3. **守住边界** `classmateBoundaries`：拒绝公权介入，帮助朋友分析商业计划；两年后重新审视朋友间的财务界限，五年后同学会重逢。

新增 6 个独立节点 `arc_classmate_(open|favor|boundary)_(2|3)`，每条线按“起点 → 两年后 → 再三年后”推进。三条路线接入既有 `contacts`、`flags`、`careerLog`、年度事件面板和存档；不存在并行 NPC 数据库。职业页新增林默进度卡，不提前透露结局。

### 真实修复的长期因果优先级

原 `_rcy_annualEventSelection` 即使已根据旧 flag 创建当年新的健康/学历/人物入口，也可能在同一年调用刚性链时把入口直接覆盖为另一事件，导致首次选择的故事凭空消失。已调整为：**政策项目优先 → 到期的长期剧情节点 → 新故事入口 → 普通随机池**；已到期剧情不会抢占正在显示的选择事件，也不会被新故事覆盖。专门新增回归测试。

## 3. 存档与离线升级

保留所有旧的 `shangan_save`、`shangan_save_N` 浏览器存档键。新增 flag 在旧档 `migrateState` 中补齐时间戳，不会清除玩家数据。`sw.js` 缓存版本升级 `shangan-pages-7`，脚本引用版本升级到 v2.1.86，防止用户长期拿到上一版本脚本。安装新 SW 时仅更换旧 `shangan-pages-*` 缓存，不涉及 localStorage 存档。

## 4. 执行过的测试

本地 Box Linux，Node.js 24.21.0、Google Chrome headless + Playwright。启动静态服务后运行：

```bash
node --test tests/game-smoke.test.mjs tests/round1-engine.test.mjs tests/round2-content.test.mjs tests/round3-content.test.mjs
node tests/round3-simulation.cjs
node tests/event-content-audit.cjs --write-catalog --catalog=docs/EVENT_CONTENT_AUDIT_ROUND3.csv
GAME_URL=http://127.0.0.1:4189/ node tests/round2-browser.cjs
GAME_URL=http://127.0.0.1:4189/ node tests/round3-browser.cjs
GAME_URL=http://127.0.0.1:4189/ node tests/round1-exam-browser.cjs
```

- 静态 + 单元测试：**23/23 通过**。包含旧版导入、存档兼容、三条老同学支线的二年/五年后实际年度注入、过多选项精简、剧情即时效果、旧人物线回归、优先级抢占回归。
- 浏览器：**1440×900、390×844、360×740** 三个视口；浅色/深色、笔试/面试/入职、林默人物卡、选择反馈、保存/读取、390px 断网刷新。未发现页面级横向溢出、页面 JS 错误、资源 4xx。**不是**全部 1,799 个事件的逐键浏览器遍历。

## 5. 发布与限制

本轮按用户明确指令申请更新正式 `main`。GitHub PR/CI/Pages 最终状态须以 GitHub 真实工作流和线上页面核对为准，**不能因为本地测试成功就认定发布成功**。旧 ATLAS、灵感日报及其自动同步系统不在改动范围。

剩余的有效后续任务：所有结局长局模拟与完整退休回归；对生活/财务事件做更细致的策略强弱测试；对历史纪事建立明确时间轴（不能只用人物年龄代替事件发生年份）。
