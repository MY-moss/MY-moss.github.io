# 上岸模拟器 · 第 23 轮维护（v2.1.97）

日期：2026-11-24。基线为正式 main 的 `6b40b96`（v2.1.96），仅调整游戏、测试与发布文档；没有恢复 ATLAS、个人新闻/灵感数据，也没有删除或重置旧存档。

## 本轮实际发现的 P1 问题

`migrateState` 需要在旧存档缺少 `_since` 时补足因果链时间，但迁移名单是手写的。最新版本新增的 `wangDispute`、`directorDispute`、`mentorMet`、`mentorCared`、`cadreInquiry`、`parentCareReviewed` 等因果 flag 未全部录入。旧存档已有这些 flag 却无 `_since` 时，`getPendingCausalConsequences` 用“当前年龄 + delay”计算预计年份，每次查看都会向后滑动，使故事永久无法到期。

修复：仍保留已有迁移名单，同时从真实 `getCausalChainSteps()` 自动收集全部参与延迟链的 flag，只为缺失、无效或非正数的时间戳补当前年龄，不覆盖已存在的有效记录。不删除玩家经历、已完成事件或职业记录。既有老档按恢复时年龄开始计时，这是未知历史发生年份时的保守兼容方案，不伪造“当年实际发生”的年份。

## 新增家庭长期章节

原来“冰箱上的蓝色便签”仅有起点与两年回响，两年事件的不同处理方式都只记录 `familyClinicResolved`，从此没有长期区别。

- 将两年回访的四种选择分别记录为 `familyClinicRoutine`（固定陪伴）、`familyClinicNegotiated`（弹性协调）、`familyClinicRepair`（失约后的修复）、`familyClinicRebalanced`（分工补位），同时保留原 `familyClinicResolved` 以兼容旧档。
- 新增 `arc_family_clinic_3`“五年后，日历上的空白处”，从第二幕起延迟三年，采用刚性因果调度，已有积压的旧事继续优先。四种真实前史决定正文和选项结果，不改写公共事件模板。
- 将许砚团队排班路线引入该章节：合理交接的经历可能帮助家庭时间安排，长期把任务留给新人则需要额外的职业协调成本。跨线影响较小，避免数值惩罚压过叙事选择。
- 生涯持续故事卡、人生线路图的“已完结”状态都以真实第三幕完成为准；读档后未结束的旧家庭线仍展示待兑现时间。

新增 1 个事件，装配总数 **1,835**。旧事件 ID 均保留，未变更 localStorage 存档键或导出格式；PWA 静态缓存更新至 `shangan-pages-19`，不清理用户本地档。
