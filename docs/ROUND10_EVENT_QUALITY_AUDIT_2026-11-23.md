- ID 重复：0；标题完全重复：0；正文完全重复：0。

- 唯一一组完全相同的选项文本出现在 e631/e665，分别对应男女视角的见家长事件，属于有意镜像，不视为重复事件。

- 结构扫描中的孤立门槛提示主要由引擎运行时写入 flag 导致；没有把静态扫描误报直接当作内容缺陷。

## 60 条人工抽样的主要发现
1. **结果与数值承诺不一致**：例如 enl183 的“压力清零”实际只有 mentalPressure -2。已修正文案。
2. **选项价值方向不合理**：ent025 的“按政策办”原先扣情商、廉洁，惩罚合规处理。已调整为稳妥、低幅度正向效果。
3. **无意义选项**：edl002 的“安静站着”只有零数值变化和廉洁 +1，与选项行为不符。已改为礼貌点头并给予小幅情绪/情商效果。
4. **同一事件选项强弱不合理**：e012 的“保持观望”在职位权重上不逊于主动争取，欲望增益却明显更高。已降低其收益并补足观望的机会成本。
5. **语境和用词不当**：e614 将居民笼统称为“钉子户”，并把“强制清场”写成可接受选项。已改成明确补偿、安置与合法权益的语境，并将不当做法标成绕开协商程序。
6. **法律表述过度简化**：配偶开店事件原文笼统断言配偶可以经商。已改为提示需核对岗位和相关管理规定，并强调公职人员不得违规参与经营或利用职权影响力。
7. **人物关系数值与行为不一致**：ent155 主动接受贵人推荐原来反而降低贵人关系。已修正关系变化方向。
8. **重复剧情但无状态闭环**：enw261/enw262 描述已经挂职归来、申请留任，却没有借调前置状态，也没有真正执行留任/回原单位状态变化。已移除，统一使用 ent299→ent300→ent301 的借调链。
